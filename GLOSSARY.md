# ENV / SKEW Build Tutorial

An interactive, human-in-the-loop hardware engineering tutorial documenting how to design, fabricate, and publish the 6 HP Eurorack `ENV / SKEW` module from Hagiwo's starting sketch through its companion site.

## Adopted Upstream Vocabulary

All hardware, mode, and companion-site archetype terms are adopted verbatim from [`reference/GLOSSARY.md`](reference/GLOSSARY.md):

- **Hardware & Modes:** **`ENV / SKEW`**, **Envelope Follower Mode**, **Asymmetric Skew Limiter Mode**
- **Companion Site Archetypes:** **Curated Page**, **Patch Guide**, **Build Checklist**, **Reference Spec**, **Static Passthrough**

## Cross-Repo Identity

**Build Tutorial**:
This tutorial repository (`domesticmouse/EnvelopeFollower`) and its published tutorial site (`ENV / SKEW Build Tutorial`) guiding builders from sketch to finished module and companion site.
_Avoid_: Codelab, docs site, companion site

**Companion Site**:
The live documentation site published by the `ENV / SKEW` hardware repository (`domesticmouse/EnvelopeFollowerWithSkewLimiter`).
_Avoid_: Docs site, documentation portal, module website

**Hagiwo Sketch**:
Hagiwo's original `$4` hand-drawn envelope follower schematic (`EnvelopeFollower.webp`) that serves as the pre-upgrade baseline circuit.
_Avoid_: Base sketch, original diagram, reference schematic
